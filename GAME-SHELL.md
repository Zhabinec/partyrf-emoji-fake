# Общий каркас PartyRF

«Эмодзи-фейк» служит образцом для следующих игр. Переносим сценарий входа, комнату, меню, таймеры, тестовый режим и подачу финала. У каждой игры свои действия, секреты, правила победы, темп, оформление и звук.

## Путь игрока

1. **Старт.** Название, короткое объяснение механики, вход по коду, создание комнаты и отдельная кнопка «Тест с ботами». Ссылка с кодом заранее заполняет поле приглашённому игроку.
2. **Лобби.** Код и копируемая ссылка, список участников, отметка хоста. Хост запускает партию после набора минимального числа игроков.
3. **Перебивки.** Короткий экран на всех устройствах перед новым этапом. В «Эмодзи-фейке» это сканирование паспорта, объявление досмотра и «Пора сделать выбор!». Сервер переключает фазы, чтобы отсчёт действия начался после перебивки.
4. **Раунд.** У игрока есть понятное действие, таймер и подтверждение. После отправки показываем ожидание и число готовых, где это уместно. Во второй игре все тайно выбирают эмодзи, затем видят общие карточки и обсуждают их. В другой игре сюда встаёт её собственная механика.
5. **Финал.** Сначала крупный вердикт, затем один момент из реальных действий игроков, затем послесловие с подробностями и кнопкой новой партии. Хост листает финал, остальные видят те же экраны. Во второй игре это роли, улика из багажа и архив таможни.

## Постоянные элементы

- **Шапка.** Символ и название выровнены по центру одной строки. Справа одно «Меню». Внутри «Звук» и, если игрок в комнате, «Выйти из комнаты». На узком экране код комнаты занимает отдельную строку. Меню закрывается по Escape и клику снаружи, после закрытия окна звука фокус возвращается в шапку.
- **Звук.** У каждого игрока отдельные ползунки музыки и эффектов. Настройки хранятся в его браузере. Воспроизведение запускается после действия игрока, громкость фона зависит от фазы, а короткие эффекты отмечают выбор, смену этапа, конец таймера и раскрытие. Ассеты локальные, источники и лицензии указаны в README и, где требуется, в игре.
- **Адаптив.** На узких экранах одна колонка, длинные имена и темы переносятся, основные кнопки доступны пальцем. Декоративное движение учитывает `prefers-reduced-motion`. Проверяем старт, комнату, активный раунд и финал, в том числе при ширине 320 px.
- **Выход и возврат.** Сессия восстанавливается после обновления вкладки. Явный выход очищает её и возвращает на старт. Если уходит хост, сервер передаёт управление другому живому игроку. Комната без живых игроков закрывается.

## Где брать реализацию

| Файл во второй игре | Что делает |
| --- | --- |
| [server.mjs](server.mjs) | Комнаты, токены, вход и выход, передача хоста, раздача статических файлов. Вызывает правила игры и возвращает персональный снимок состояния. |
| [src/game.mjs](src/game.mjs) | Фазы, дедлайны, проверки действий, ход партии и подсчёт результата. Для новой игры здесь пишем её правила. |
| [src/main.js](src/main.js) | Действия из интерфейса, запросы к серверу, опрос комнаты, отрисовка по состоянию и показ оставшегося времени. |
| [src/ui.js](src/ui.js), [index.html](index.html), [styles.css](styles.css) | Шапка, формы, сцены, карточки, анимации и адаптив. Компоновка общая, визуальный язык зависит от темы игры. |
| [src/audio.js](src/audio.js) | Фоновая музыка, эффекты и локальные настройки. Для новой игры меняем звуки и привязку к событиям. |
| [src/test-bots.mjs](src/test-bots.mjs) | Режим для одиночного прогона. Боты действуют через те же правила игры. При `TEST_BOTS=0` сервер скрывает кнопку и отключает создание тестовой комнаты. |

Сервер решает, когда фаза заканчивается, какие действия допустимы и кто победил. Клиент показывает остаток времени по серверному дедлайну. Секреты, чужие варианты и результаты выдаём только тем игрокам и на тех этапах, где их можно показывать. Для переходов используем номер этапа, чтобы запоздалое нажатие не применилось к следующему раунду.

Перед сдачей проходим полную партию с ботами, затем проверяем вход по ссылке и синхронизацию с нескольких устройств. Отдельно проверяем истечение таймера, повторный запуск, выход хоста, меню на телефоне и раздельное выключение музыки и эффектов.
