# Эмодзи-фейк

## Играть компанией через интернет

**[Открыть игру](https://partyrf-emoji-fake.onrender.com/)** · от 3 игроков · каждому нужен только браузер.

1. Один участник открывает ссылку, вводит имя и нажимает «Создать комнату».
2. В лобби он копирует приглашение и отправляет коллегам. Каждый открывает его на своём устройстве, вводит имя и входит в ту же комнату.
3. Когда собрались минимум трое, хост начинает партию. Ничего устанавливать или регистрировать участникам не нужно.
4. Для телевизора или трансляции хост открывает **«Меню → Открыть общий экран»**. Игроки продолжают отвечать со своих устройств. При игре из разных мест используйте отдельный голосовой звонок: встроенного голосового чата нет.

Демо работает на бесплатном Render. После простоя первое открытие может занять около минуты. Дождитесь загрузки и создайте новую комнату. Все участники используют один адрес игры; комнаты между разными играми не общие.


## Проверка живой компанией

Один организатор скачивает этот репозиторий, устанавливает [Node.js 22+](https://nodejs.org/) и запускает из папки игры команду ниже. Зависимостей нет, устанавливать пакеты не требуется. Остальные участники открывают игру в браузере; каждый отвечает со своего устройства. Минимум три игрока.

1. Организатор выполняет `node server.mjs`. Терминал оставляет открытым.
2. Для устройств в одной Wi-Fi/локальной сети: узнайте IPv4 компьютера командой `ipconfig` и откройте `http://ЭТОТ-IP:4175` на всех устройствах. При первом запуске разрешите Node.js доступ в частной сети в брандмауэре Windows. Гостевая Wi-Fi-сеть может изолировать устройства.
3. Организатор создаёт обычную комнату и копирует ссылку из лобби. Остальные входят по ней со своими именами. Ссылка с `localhost` работает только на компьютере организатора — для телефонов нужен адрес из шага 2.
4. Хост начинает партию. Через «Меню → Открыть общий экран» можно открыть отдельную вкладку для телевизора или трансляции: это зрительский экран без личного ответа и секретного слова. Ответы вводятся на устройствах игроков.
5. Для проверки повторного подключения обновите вкладку игрока. Для проверки передачи роли хоста выйдите из комнаты через меню — управление перейдёт другому участнику.

## Проверка из разных городов

Нужен один доступный через интернет Node.js-сервер. Каждый участник **не должен запускать свою копию сервера**: это создаст независимые комнаты. Сам репозиторий не является игровой ссылкой.

Бесплатный вариант — [Render Free](https://render.com/docs/free). В репозитории есть `render.yaml`:

1. Опубликуйте код в своём GitHub-репозитории и подключите его в Render через **New → Blueprint**. Альтернатива: **New → Web Service**, среда Node, тариф Free, сборка `node --version`, запуск `npm start`.
2. Render выдаст HTTPS-адрес вида `https://имя.onrender.com`. Отправьте его участникам. Создайте обычную комнату и поделитесь её ссылкой. Участникам не нужны Node.js, GitHub или аккаунт Render.
3. В Blueprint тестовые боты отключены через `TEST_BOTS=0`. Реальные игроки подключаются к одному серверу. Для общего экрана по-прежнему доступен пункт меню у хоста.

На Free сервер засыпает после 15 минут без запросов; первый запуск после простоя может занять около минуты. Комнаты хранятся в памяти: сон, перезапуск или новая публикация сбрасывают партии. Используйте один экземпляр сервиса. Создавайте комнату после пробуждения сервера; сохранность старой комнаты не гарантируется. Это вариант для демонстрации, а не постоянного хранения партий.

Без аккаунта можно использовать [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/): установите `cloudflared`, запустите игру и во втором терминале выполните `cloudflared tunnel --url http://127.0.0.1:4175`. Откройте выданный HTTPS-адрес, создайте комнату уже по нему и отправьте ссылку участникам. Адрес работает, пока включены компьютер, сервер и туннель, и меняется при перезапуске туннеля.

## Быстрый запуск на компьютере


[Общий каркас игр PartyRF](GAME-SHELL.md)

Сетевая игра на 3–10 человек. Запуск из папки проекта с Node.js 22+:

```powershell
node server.mjs
```

Откройте http://127.0.0.1:4175. Для телефонов в одной сети создайте комнату по локальному IP компьютера с сервером. Для удалённой партии опубликуйте сервер на хостинге.

- Сервер назначает одного фейка на каждые три полных места. Все видят только своё слово. Например, большинство получает «Планета», фейки — «Круг». Роль открывается в финале.
- Три раунда. Все одновременно получают по три случайных эмодзи и за 18 секунд тайно выбирают один. Когда все выбрали или время вышло, открываются карточки с именами и эмодзи. На общий спор вслух даётся 30 секунд.
- После трёх раундов у каждого 30 секунд и один голос. Чтобы проголосовать, нажми на карточку подозреваемого с его эмодзи за все три раунда. Под подозрение попадают лидеры по голосам в пределах числа фейков. При ничьей на границе спорные места остаются незанятыми. Компания побеждает, если вычислила всех фейков.
- Перед раундами, голосованием и раскрытием ролей все видят короткие перебивки. В финале хост листает результат, улику из багажа и архив с голосами и журналом досмотра.
- «Тест с ботами» создаёт комнату с тремя ботами. Они выбирают эмодзи и голосуют. Скрыть режим можно запуском сервера с `TEST_BOTS=0`.
- Кнопка «Звук» открывает раздельную громкость музыки и эффектов. Музыка играет на устройстве каждого игрока, настройки сохраняются в браузере.

Музыка — [Space Jazz](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN2100030), Kevin MacLeod, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Эффекты — [Mixkit](https://mixkit.co/license/).
- Правила и скрытые данные находятся в `src/game.mjs`, словарь в `src/content.mjs`, HTTP и сессии в `server.mjs`. Клиент написан на HTML, CSS и JavaScript.

## Проверки

`npm test` проверяет полную партию, скрытие секретов на общем экране, повторный запуск, независимые HTTP-сессии, восстановление подключения и передачу хоста. Тесты используют локальные временные серверы без внешних зависимостей.
